主打 · One World

电脑和手机，玩的是同一个存档

要做到这一点，得同时有桌面启动器，和一个能读写安卓启动器（Zalith Launcher 2、FCL、Pojav）目录的手机端。我们两个都有。

版本、Mod、配置、存档一起过去
还是这个世界

同步的是整个实例

MC 版本、加载器、Mod、配置、存档一起过去。两边装的是同一个 Mod 文件，不会出现用低版本打开高版本存档、把世界弄坏的事。

默认不经过服务器

同一个 Wi-Fi 下扫码配对一次，之后电脑和手机直接传，不用注册、不占谁的流量。不在一个网络时，可以用自己的网盘，或者激活码开通的 LF 云。

不怕弄坏

一边在玩，另一边打开会提示「电脑上正在玩」；每次同步前在电脑上留一份历史版本，坏了能退回去——顺带也就有了存档备份。

说清楚限制：手机端只能在打开 LeafStarter 时同步（安卓启动器退出游戏时不会通知我们）；Mod 在手机上能不能跑，取决于安卓启动器本身。安卓版还在做，电脑版先来。

每天都用得上 · Direct

双击图标，直接进游戏

用启动器，99% 的时候只做一件事：进游戏。那就让这件事不需要看界面。

  • 打开「直接启动」后，双击 LeafStarter 就启动上次玩的实例，屏幕角落有 3 秒能取消
  • 按住 Shift 再双击，才打开完整界面
  • 每个实例能放一个桌面快捷方式；任务栏图标右键列出最近玩的 5 个
  • 游戏正常退出，启动器也跟着退出；崩溃了才把界面拿出来，停在出问题的实例上

和朋友 · Together

发一个邀请码，朋友就进来了

联机最常卡住的不是网络，是 Mod 对不上。LeafStarter 的邀请码里带着实例清单：朋友那边自动建一个一模一样的实例、装好 Mod，点一下就进你的世界。

1

你在游戏里「对局域网开放」

启动器从游戏日志里认出端口，右下角问一句：邀请朋友？

2

复制邀请码发过去

LS1.dVZJkuJWEL2Kg221…已复制本机能给朋友的地址（公网 IPv6、局域网、Radmin VPN）都自动认好、打进去了。

3

朋友粘贴，点一下

能连上哪个地址先测好；没有一样的实例就照着建，装完自动启动、直接进你的世界。

朋友用别的启动器也行

邀请码旁边能只复制地址；邀请链接 leafstarter:// 点一下就打开 LeafStarter。P2P 组网（两边都在 NAT 后面也能连）和樱花穿透一键开隧道还在做。

要一个一直开着的服

买好云服务器，填 IP 和密码，剩下的——装 Java、装服务端、只带服务端要的 Mod、开端口、开机自启、定时备份——启动器按固定剧本做完。还能把本地存档一键搬上去。

不只是告诉你「Java 版本不对」，而是给一个「换成 Java 17 重新启动」。

  • 常见崩溃靠规则秒出结果：免费、离线、不用 AI

  • Claude、Cursor 这些 AI 客户端能通过 MCP 直接操作启动器

资源中心

Modrinth 和 CurseForge 的 Mod、资源包、光影，按实例的版本和加载器筛好；前置自动带上，有更新一眼看到。

整合包

导入 Modrinth、CurseForge、MultiMC、HMCL 的整合包；也能把自己的实例导出成 .mrpack 分享。

低配也流畅

新建实例选「流畅优先」，自动加 Sodium、Lithium 这类口碑好的优化 Mod，按内存和显卡调好参数；一键加上，一键撤掉。

智能汉化

Mod 自带中文的不动，没有的先用社区汉化，再不够用 AI 补齐，做成资源包叠在最上面，不改 Mod 文件。

皮肤工作台

像素编辑加 3D 预览，也能用一句话让 AI 画；正版账户一键换上，披风也能换。

不进游戏管世界

看地图和种子、查村庄要塞在哪、改游戏规则和天气，都不用进游戏。

笔记本跑满性能

强制用独显、提高进程优先级、切出去不降速——笔记本上 MC 跑在核显上，是最常见的「卡」。

正版、离线、外置

微软账户设备码登录，令牌用系统加密存着；离线账户和 authlib-injector 外置登录也支持。

Everything is Plugins

做一个自家专用的启动器

服主和整合包作者不写代码，填表就能导出一个签名的定制包：换名字、换主题、带上整合包和服务器、关掉用不上的功能。玩家打开就是你的样子，程序还是同一个、跟着官方自动更新。

开发者能写插件：换外观、加卡片和命令、加崩溃规则、给 AI 助手加工具。开放有边界——令牌和密钥插件永远拿不到，按权限办事，坏插件能一键吊销。

问答 · FAQ

常见问题

和 PCL、HMCL 比有什么不一样？

崩溃分析、整合包、Mod 下载、正版登录这些，PCL 和 HMCL 都做得很好，LeafStarter 也有。不一样的是：电脑和手机玩同一个存档；双击图标直接进游戏；邀请码里带着 Mod 清单，朋友那边自动装好；出了错给一个修好的按钮。LeafStarter 也能直接用 PCL、HMCL、官方启动器的游戏目录，不用搬家。

要钱吗？要注册吗？

不要。启动器开源免费，没有账号系统。只有跨网络同步用的 LF 云需要激活码（局域网直传、自己的网盘都免费）；AI 功能用你自己填的 Key，不填也不影响别的功能。

我的账号安全吗？

微软账户用官方的设备码登录，启动器拿不到你的密码；令牌用 Windows 自带的加密存在你自己电脑上，日志里会自动打码。插件永远拿不到令牌和密钥。

自动更新会打断我吗？

不会。新版本在后台下好、核对签名后放在旁边，你关掉启动器时换上，下次打开就是新的——不弹安装窗口、不用点下一步。想立刻换，点「现在重启」就行。

杀毒软件报毒怎么办？

新启动器还没有积累信誉，又会启动 Java 进程，偶尔会被误报。我们会给正式版做代码签名；在那之前，可以从 GitHub 的源码自己编译核对。

数据放在哪？能整个带走吗？

安装版放在你的用户目录里（设置 → 关于能打开）。便携版放在 exe 旁边的 data 文件夹，整个文件夹拷走就行。游戏本身还在原来的 .minecraft 里，LeafStarter 不搬它。

安卓版什么时候有？

电脑版先公测，安卓端接着做。安卓端只管同步和投递：把电脑上的实例写进你常用的安卓启动器，游戏还是在那个启动器里玩。
