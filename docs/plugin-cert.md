# 原生插件开发者认证

原生插件会在玩家电脑上运行你自带的程序，权限最大，所以要先认证开发者，由 LeafStarter 发一张证书（用官方根密钥签你的作者公钥）。没有有效证书的原生插件装不上。外观、声明式、脚本插件不用认证。

## 怎么申请

1. 在你自己的电脑上看作者公钥：`leafstarter --cli plugin-key`（以后所有插件都要用这台电脑上的这把密钥签，别弄丢）。
2. 在仓库提一个「原生插件开发者认证」Issue（模板里有要填的项）：作者公钥、插件要做什么、为什么非得用原生程序、源码地址。
3. 实名：维护者会通过邮件联系你核对身份（只核对，不公开、不存档证件）。未成年开发者请让监护人一起联系。
4. 通过后，维护者用离线保存的根密钥执行 `leafstarter --cli plugin-cert <根私钥文件> <你的作者公钥>`，把得到的证书回复给你。把它写进 `plugin.json` 的 `cert`。

## 会被吊销的情况

偷账户令牌或密钥、在玩家不知情的情况下联网传数据、捆绑无关程序、证书借给别人用。吊销后插件市场的吊销名单会让它在所有人那里自动停用。
