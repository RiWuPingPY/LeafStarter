# LeafStarter 规划

把「方块补给」（Minecraft 版本与加载器下载器）做成一个真正能用、而且让人想换过来的 Minecraft Java 版启动器。

第 3 节的决策 11-23 都定了（D6 有一处 11-24 新发现的待定）；以后有新的要拍板的事，标 **【待定】**。

---

## 0. 现状：方块补给 0.1.0 已经有什么

| 模块 | 现在做什么 | 在启动器里怎么用 |
|---|---|---|
| `net.rs` | 多源下载：URL 改写、测速打分、按文件回退、限流冷却、SHA1 校验 | **原样复用**，所有下载都走它，也是「快」这个卖点的底子 |
| `mojang.rs` | 版本清单；版本 JSON → 文件清单；加载器 JSON 合并成独立版本 | 复用来「补全文件」；新增 `inheritsFrom` 链解析 |
| `loaders.rs` / `forge.rs` | Fabric / Quilt / Forge / NeoForge 版本列表与安装（含处理器） | 保留，作为「新建实例」 |
| `java.rs` | 找本机 Java；下载 Mojang 运行时 | 扩展为按版本 JSON 自动选、按 component 下载 |
| `launchers.rs` | 识别本机启动器和它们的 `.minecraft` | 演变为「游戏目录」：别的启动器的目录直接导入、直接启动 |
| `platform.rs` + `McBridgePlugin.kt` | 安卓：查已装启动器、文件授权、读写 ZL2 / FCL / Pojav 的目录 | **跨端卖点的底子**：别人没有的能力 |
| `install.rs` / `task.rs` | 安装流程；任务进度推送 | 任务系统泛化 |
| `src/` | 原生 HTML/CSS/JS 前端 | 保留技术栈，**交互重做**（见第 2 节） |
| `site/` | 官网 + R2 发布 + 下载统计 | 加自动更新接口、CurseForge 代理、LF 云（激活码，见 5.7） |

## 1. 竞争力：凭什么一看就想下载

崩溃分析、整合包、Mod 下载、正版登录这些，PCL / HMCL 都有，做了只算及格，不会让人换。要有一句话就能说清、别家给不了的东西。

### 主打：手机电脑，同一个世界

> 在家用电脑玩的存档，到学校打开手机接着玩；回家再接着用电脑玩。

- **为什么是我们**：要做到这一点，得同时有桌面启动器和一个能读写安卓启动器（ZL2 / FCL / Pojav）目录的手机端。后者是方块补给已经做好的、最难的一块，别人没有。
- **做法**：电脑和手机上的 LeafStarter 直接传，默认不经过我们的服务器，也不用注册账号。同一个 Wi-Fi 下扫码配对一次；手机打开 LeafStarter 时把电脑上开了同步的实例拉下来，写进你常用的那个安卓启动器的目录；手机玩完回到 LeafStarter，再传回电脑。不在同一个网络时，可以用自己的网盘，或者用激活码开通的 LF 云（见 5.7）。
- **同步的单位是「实例」**：MC 版本、加载器、Mod 列表、配置、存档一起同步，两边版本始终一致，不会出现用低版本打开高版本存档把世界弄坏的事。Mod 两边装的是同一个文件，不会因为版本不同出问题。
- **防冲突**：一边在玩时，另一边打开会提示「电脑上正在玩」；每次同步前在电脑上留一份历史版本，坏了能退回去——顺带也就有了存档备份。
- **限制要说清**：手机端只能在打开 LeafStarter 时同步（安卓启动器退出游戏时不会通知我们）；Mod 在手机上能不能跑，取决于安卓启动器本身。
- 默认的局域网直传对所有人免费，不占我们的服务器和存储；LF 云只给有激活码的人用（D23）。

### 第二卖点：双击图标，直接进游戏

日常用启动器，99% 的时候只做一件事：进游戏。那就让这件事不需要看界面。

- 设置里打开「直接启动」后，双击 LeafStarter 图标就直接启动上次玩的实例，屏幕角落有 3 秒「取消」；要进界面就按住 Shift 再双击。
- 每个实例可以生成桌面快捷方式；任务栏图标右键列出最近玩过的实例，点一下就启动。
- 打开界面时，最近的实例已经选中，按回车就启动。

### 第三卖点：低配电脑也流畅

用户里有很多拿轻薄本玩的学生。

- 新建实例时选「流畅优先」，会自动加上一组口碑好的优化 Mod（Sodium、Lithium、FerriteCore 之类，按加载器和版本挑，都来自 Modrinth），再按内存和显卡调好 JVM 参数和画面设置。
- 已有的实例也能一键加上，一键撤掉。

### 打底（必须做好，但不当卖点）

- **快**：多源下载已经有了；启动前的检查和补全并行做，目标是从点「启动」到游戏窗口出来，不比直接点官方启动器慢。
- **出错就修好**：不只是说「Java 版本不对」，而是给一个「换成 Java 17 重新启动」的按钮。
- 崩溃分析、整合包、Mod / 资源包 / 光影管理、正版 / 离线 / 外置登录。
- 每个 Mod 都能跳到它的 Modrinth / CurseForge 页、源码（GitHub 等）和 MC百科；键位、FOV 这些设置一键套用到别的实例（PCL、HMCL 都有类似的，属于打底）。

### 第四卖点：和朋友，也是同一个世界

> 发一个邀请码，朋友那边自动装好同样的 Mod，点一下就进你的世界；想一直开着，就把这个世界搬上服务器。

- **先认清现状**：2025 年 10 月起，HMCL（陶瓦联机）和 PCL2 2.11（「联机回归」）都内置了基于开源 EasyTier 的一键联机。「能联机」只是追平，差异要做在下面几条。
- **联机最常卡住的是 Mod 对不上**：邀请码里带着实例清单（就是跨端同步用的那一份）。朋友用 LeafStarter 打开，自动建好一模一样的实例再进房间；朋友用别的启动器，拿到地址和一个 `.mrpack`。
- **按场景选，不按技术名词选**：「现在就想一起玩」走临时联机（P2P、IPv6 直连、樱花穿透），「要一个一直开着的服」走常驻服务器（云服务器一键开服、导入已有服务器）。启动器按双方的网络情况替你选好路，见 5.12。
- **一个世界走三处**：电脑上玩出感情的存档，一键搬上云服务器给朋友 24 小时玩；手机端扫邀请码就能加进来。跨端同步、联机、开服共用一套实例清单。
- **开服不求人**：买好云服务器，填 IP 和密码，剩下的（装 Java、装服务端、开端口、开机自启、定时备份）启动器按固定剧本做完，卡住了 AI 接着查。

### 加分项：AI 助手和 MCP

- **规则先行，AI 兜底**：常见崩溃靠规则秒出结果，免费、离线；规则认不出的交给 AI 读日志、查 Mod 信息、给方案，你确认后执行并自动重启验证。
- **自动二分查冲突 Mod**：几百个 Mod 里找出捣乱的那个，全程自动，不需要 AI。
- **MCP**：让你已经在用的 AI 客户端（Claude、Cursor、Cherry Studio 等）直接操作启动器。
- **不绑模型、不强制付费**：用户自己填 Key；不填，除 AI 以外的功能照常用。见 5.13。

### 加分项：游戏外的工具箱

班上同学提的一批功能，挑出值得做的（细节见 5.8、5.14–5.17）：

- **看不懂的 Mod 自动汉化**：先用社区人工汉化，没有的再用机器或 AI 补齐，做成资源包叠在最上面，不改 Mod 文件。
- **自己搓皮肤**：内置皮肤工作台，像素编辑加 3D 预览，也能让 AI 按一句描述生成；正版账户一键换上。你的皮肤还会站在每个实例的风景头图里。
- **不进游戏也能管世界**：看种子和世界信息、看地图、查村庄要塞在哪、改游戏规则；默认关闭的「局外指令台」能让 AI 帮你写命令。
- **笔记本跑满性能**：强制用独显、只用性能核、切出去不降速，再配上按显卡推荐的渲染器。
- **想简洁就简洁**：大功能做成可选的「功能包」，不装就不跑、不占后台。

### 增长：插件和定制版（Everything is Plugins）

- 服主、整合包作者能用 LeafStarter 做「自家专用启动器」：换名字、换主题、带上整合包和服务器，不用写代码。每个定制版都带着「基于 LeafStarter」进到他们玩家手里，这是拉新最快的渠道。
- 开发者能写插件：加功能、改界面、换字体、加崩溃规则、给 AI 助手加工具。官方功能自己也按插件来写。
- 开放有边界：令牌和密钥永远拿不到，按权限办事，坏插件能一键吊销。详见 5.18。

官网首屏一句话：**手机电脑，同一个世界。**

## 2. 交互：为什么不顺手，改成什么样

### 2.1 现在的问题（从代码里量出来的）

「挺弹」恰恰是问题所在：第一次看觉得灵动，每天用几十次就变成了等待。

| 现象 | 代码里的事实 | 用起来的感觉 |
|---|---|---|
| 切页要等 | 每次切页，内容从下往上弹入：460ms 带回弹，加最多 150ms 错峰，**约 0.6 秒才停稳** | 手比眼快，点下去时目标还在往上走 |
| 列表飞入 | 切筛选时最多 24 行依次飞入，最后一行约 **0.7 秒**才到位 | 想点的那行还没落定 |
| 余光里总有东西在动 | 背景两团光斑无限旋转（60 秒、75 秒一圈），叠在毛玻璃面板后面；状态点、进度条也一直在闪 | 不看它也会被它吸引注意力；文字对比度跟着背景变 |
| 位置不固定 | 每页顶部一个大标题，切页时文字换掉；切页还会自动滚回顶部，回来时列表位置丢了 | 同一个按钮每次出现在不同的高度 |
| 关键动作藏在弹窗里 | 装一个版本要进弹窗走好几步；弹窗出现也带缩放回弹 | 每次都得「看」着操作 |
| 没有键盘 | 整个前端没有任何键盘处理，`Esc` 关不掉弹窗，回车不能确认 | 手离不开鼠标 |
| 打开就是目录 | 首页是「全部版本」列表，不是「我的游戏」 | 每次都要先找 |

### 2.2 新的原则：不用看也顺手

1. **位置恒定**：启动按钮、实例列表、导航，在任何页面都在同一个位置，加载前后不挪动（数据没来时用同尺寸的占位）。
2. **框架不动，内容会动**（第二版修正：第一版把动画全拿掉，结果好用但没生气）：左栏、顶栏、启动键这些天天点的东西永远不挪位置，它们靠颜色、光、按下的手感、滑过去的指示条来反馈；内容切换时淡入并上浮几像素，0.25 秒内落定，动的过程中照样能点。删掉的行先收拢再消失，撤销时展开回来，让人看得见变化发生在哪。
3. **好看要有记忆点**：每个实例一幅按种子生成的像素风景头图，你的角色站在里面，云慢慢飘；启动时按钮里有流光，启动成功蹦出一把经验球。卡片用柔和投影分层，紫到蓝的渐变用在启动键和指示条上。不在文字后面放会动的东西，也不用毛玻璃压文字。
3b. **动效自己管**：设置里「动效：完整 / 精简 / 跟随系统」，默认「完整」。很多 Windows 关着系统的「动画效果」（开发机就是），浏览器因此报告「减少动态效果」；如果直接跟系统走，启动器就一点动静都没有了。
4. **不打断**：主要流程不用弹窗，改成侧边面板或页内展开；删除这类操作不弹确认，直接做（进回收站）并给「撤销」。
5. **键盘可达**：回车启动、↑↓ 选实例、`Ctrl+K` 命令面板（「装 1.20.1 Fabric」「打开 mods 文件夹」「启动 xxx」）、`/` 搜索、`Esc` 关闭、`Ctrl+1…5` 切页。
6. **记住上下文**：上次的页面、筛选、滚动位置、选中的实例。
7. **默认就对**：Java、内存、版本隔离这些自动选对，大多数人一辈子不用打开设置。

### 2.3 新布局

- **左栏是「我的实例」**，常驻：图标、名字、版本、上次游玩；顶上是搜索和「新建」。
- **右边是选中的实例**：上面是它的像素风景头图，下面是 Mod / 存档 / 截图等标签页；大启动按钮固定在右下角。
- **账户**在左栏底部，一下就能切。
- **下载、任务、设置**从顶部的窄导航进，或者直接用 `Ctrl+K`。
- 视觉延续 LeafHub 的紫色和衬线字：衬线字用在品牌、实例名和页面标题，正文用无衬线字体；列表行高 52px 左右，圆角 10–16px。

### 2.4 怎么验证

你说不清哪里不对，那就让手来判断：先做一个可以点的原型（新布局 + 首页 + 实例页，用 mock 数据），和现在的版本并排各用一天，确认手感对了再全面铺开（M1）。

可以量的验收标准：
- 老用户从双击图标到游戏开始加载：0 次点击（直接启动）或 1 次（回车）。
- 任何切页后 100ms 内目标可点，之后不再移动。
- 高频路径全部能用键盘完成。

## 4. 总体架构

### 4.1 核心概念

- **游戏目录**：一个 `.minecraft`。来源：自带默认目录、识别到的其他启动器目录、手动添加。
- **实例**：游戏目录里的一个版本（`versions/<名字>/`）。开启版本隔离时，游戏运行目录是 `versions/<名字>/`。
- **账户**：微软 / 离线 / 外置（authlib-injector）。LF 云不用账号，输入激活码开通（见 5.7、D23）。
- **同步实例**：开了同步的实例，有一份清单（版本、加载器、Mod 列表、配置、存档快照），跟着同步传到另一台设备。
- **邀请码**：连接方式 + 实例清单（和同步用的是同一种清单）。朋友凭它装好同样的实例并进服。
- **常驻服务器**：一台由 LeafStarter 管理的 MC 服务器（自己的云服务器或面板服），记录连接方式，凭据放保管库。
- **任务**：安装、补全、下载 Mod、导入整合包、下载 Java、同步、开服剧本、运行中的游戏。
- **设置**：全局 + 实例覆盖。

### 4.4 数据存放

- 应用数据目录：`settings.json`（带 `schemaVersion`）、`accounts.json`（令牌加密：Windows 用 DPAPI，安卓用 Keystore）、`vault.json`（SSH 私钥、云 AccessKey、樱花密钥、模型 Key，同样加密）、`servers.json`（常驻服务器和面板的连接信息，不含密钥）、`gamedirs.json`、`cache/`、`java/`、`logs/`、`plugins/`（官方和第三方插件，每个一个目录，各自的数据也在里面）、`dist/`（定制包）、`i18n/`（译文缓存，按原文哈希）、`skins/`（皮肤和历史版本）。便携版把这些都放在 exe 旁边的 `data/` 里。
- 实例设置：`versions/<名字>/LeafStarter/instance.json`，跟着版本文件夹走。
- 本地历史：每个同步的世界在电脑上留最近几份快照，放在 `versions/<名字>/LeafStarter/history/`。
- LF 云（Cloudflare R2，只给激活码用户）：每个同步实例一份清单 + 按内容哈希存的文件（只存世界和配置；Modrinth、CurseForge、Mojang 的公共文件只记来源）+ 少量历史快照。每个激活码配额固定。

### 4.5 安全

- 现在 `csp: null` 且 `withGlobalTauri: true`：一旦显示远程内容，被注入的脚本能直接调后端命令。要开严格 CSP；远程介绍在 Rust 里转 HTML 并清洗（`pulldown-cmark` + `ammonia`）。
- 访问令牌不落日志，导出日志和崩溃报告时打码。
- 整合包、Mod、同步下来的文件一律做路径穿越检查。
- 启动前命令、wrapper 命令只能用户本人在设置里填，整合包和同步都不能带进来。
- SSH 私钥、云 AccessKey、樱花密钥、模型 Key 和账户令牌一样加密保存；Agent 和 MCP 只能「用某个凭据做某件事」，拿不到明文。
- 发给 AI 模型的内容先打码（用户名路径、令牌、IP、密码），发出前可以预览；日志、Mod 介绍、MOTD、网页里的文字一律当数据，里面写了什么都不会放宽权限。
- P2P 联机只转发 MC 端口，不把整台电脑暴露给虚拟网络里的人。
- **不暴露服务器**：启动器只连 Cloudflare 上的域名（LF 云、自动更新、CurseForge 代理）、GitHub（插件索引）和各官方源，从不直连我们自己服务器的 IP。LF 云的上传下载用 Worker 签发的短时效链接直连 R2，桶不公开；Worker 按激活码和 IP 限流。
- **局域网直传**：只在局域网地址上监听，不对公网开放；扫码配对用一次性密钥，之后的传输加密；没配对过的设备连不上。
- 插件（含官方功能包）：清单里声明要的权限，装之前用大白话给用户看；权限变多要重新同意。令牌、保管库明文、我们的 API Key 不在任何插件接口里。插件界面放在拿不到 IPC 的隔离环境里。签名 + 吊销名单 + 安全模式（按住 Ctrl 打开，不加载插件）。见 5.18。
- 局外改世界、指令台：先快照；游戏开着这个世界时不动它。

## 5. 功能

### 5.1 启动核心

点「启动」之后：

1. **解析版本**：沿 `inheritsFrom` 合并；`jar` 字段决定客户端 jar。
2. **选 Java**：实例指定 > 全局指定 > 自动。自动按 `javaVersion.majorVersion` 选「刚好满足」的那个，不选最高的；没有 `javaVersion` 的老版本按 Java 8。找不到就按 `javaVersion.component` 下载 Mojang 运行时。
3. **准备账户**：微软令牌快过期才刷新；外置登录先校验再刷新；离线生成 UUID。
4. **补全文件**：默认按大小快速检查，可选完整 SHA1；缺的多源下载。和第 2、3 步并行。
5. **natives**：1.18 及更早的 `natives` + `classifiers` + `extract.exclude`，和 1.19 起库名带 `natives-windows` 之类分类器的写法，统一解压到 `versions/<名字>/natives-<系统>-<架构>/`，跳过 `META-INF`。
6. **旧版资源**：`virtual` 索引拷到 `assets/virtual/legacy`，`map_to_resources` 拷到 `resources/`。
7. **拼参数**：新写法 `arguments.jvm / game` 按 rules（系统、架构、features）判定；老写法 `minecraftArguments` 自己补 JVM 参数；替换全部占位符；加内存、用户参数、log4j 配置、外置登录的 `-javaagent`、窗口大小、自动进服（1.20+ 用 Quick Play，老版本 `--server` / `--port`）。Java 9+ 用 `@参数文件` 规避 Windows 命令行长度上限。
8. **起进程**：Windows 用 `javaw.exe`、不弹控制台；支持 wrapper 和启动前命令。
9. **日志**：实时推到日志面板；解析官方 log4j 配置输出的 XML 事件；每次运行存一份。
10. **状态**：游戏窗口出来后按设置隐藏 / 最小化 / 关闭启动器；退出码非 0 且不是用户结束的 → 崩溃分析；开了同步的实例 → 上传。
11. **多开**：同一实例重复启动先提示；不同实例可以同时跑。

### 5.2 直接启动

- 「直接启动」开关：双击图标 → 角落一个小窗显示「3 秒后启动 xxx · 取消」→ 启动 → 小窗消失，主界面从头到尾不出现。按住 Shift 双击则正常打开界面。
- 桌面快捷方式：带实例图标，命令行参数 `--launch <实例>`。
- 任务栏跳转列表：最近 5 个实例。
- 单实例：再次打开时把参数交给已运行的那个（`tauri-plugin-single-instance`）。

### 5.3 出错就修好

- 读本次输出尾部、新生成的 `crash-reports/`、`hs_err_pid*.log`、`logs/latest.log`、Forge 的 `logs/debug.log`。
- 首批规则，每条都带一个修复按钮：

| 原因 | 修复按钮 |
|---|---|
| Java 版本不对 | 换成合适的 Java 并重启（没有就下载） |
| 内存不够 | 调大内存并重启 |
| Fabric / Forge 缺依赖 | 从 Modrinth / CurseForge 补装 |
| Mod 重复 | 禁用旧的那个 |
| Mixin 失败（能定位到 Mod） | 禁用那个 Mod 并重启 |
| 文件损坏 | 补全文件并重启 |
| 显卡驱动 / OpenGL | 打开显卡驱动下载页 |
| 老版本游戏路径有 `!` 等字符 | 提示换目录 |

- 能提前查的放到启动前检查里。

### 5.4 账户

- **微软**：设备代码登录（桌面、安卓通用；桌面也可以浏览器 + 本地回调）。链路：Microsoft OAuth → Xbox Live → XSTS → Minecraft `login_with_xbox` → 查是否拥有游戏 → 取档案。XSTS 常见错误码给中文说明。刷新令牌加密保存，启动前按需换新。
- **离线**：按 D6，中国大陆 IP 直接能加；大陆以外要先在这台设备上登录过一次正版。界面上提醒「离线账户进不了开了正版验证的服务器」。用户名校验；UUID 默认与 Java 端一致的 `OfflinePlayer:<名字>` 名称 UUID。
- **外置**：authlib-injector，支持 ALI 自动发现；启动时加 `-javaagent` 和预取的服务器元数据。
- **LF 云**：输入激活码开通，只用于同步，和游戏账户无关；没有用户名、密码，也不收集手机号（见 5.7、D23）。

### 5.5 实例管理

- 左栏列表：按游戏目录分组；收藏、搜索、排序；同步状态小图标。
- 实例页：概览（启动、打开文件夹、补全、复制、重命名、删除进回收站、导出整合包、开关同步）、设置（每项显示「继承全局」或「已覆盖」）、Mod / 资源包 / 光影 / 存档 / 服务器 / 截图 / 日志。
- 版本隔离默认：装了加载器的实例隔离，原版共享。
- **设置模板**：键位、FOV 等从一个实例一键套用到别的实例；「存档」里每个世界能看信息、地图、查建筑、改设置。都见 5.16。

### 5.6 资源中心

- **Modrinth**：公开 API，无需 Key。
- **CurseForge**（按第三方 API 条款）：
  - Key 只放在我们的服务器，客户端请求我们的接口，由服务器转发给 CurseForge；**服务器不缓存、不存储任何 API 返回的数据**（条款明令禁止）。
  - 文件由用户的客户端直接从 CurseForge 的 CDN 下载，我们不转存、不镜像、不改动文件。
  - 作者关闭了第三方分发的文件，API 不给下载地址 → 显示 CurseForge 项目页链接让用户手动下，下好后放进指定文件夹自动识别。
  - **不用第三方镜像加速 CurseForge 内容**；国内速度靠多线程和断点续传。
  - 每个项目显示作者、链接到 CurseForge 项目页。
- **MCIM 镜像**：只考虑用于 Modrinth 内容，先核实 Modrinth 的条款。
- 搜索、按实例自动过滤、两边都有的合并显示；安装时自动带必需依赖。
- **每个 Mod 的链接**：详情页和本地 Mod 列表里给出 Modrinth / CurseForge 项目页、源码（GitHub 等）、问题反馈、Wiki、Discord（两边的接口都提供这些链接），再加一个 MC百科 搜索链接。显示中文名要用 MC百科 的数据，见 D18。
- 下载页的 Mod 介绍能一键翻成中文（用 5.14 的翻译）。
- 本地 Mod：解析 `fabric.mod.json` / `quilt.mod.json` / `mods.toml` / `neoforge.mods.toml` / `mcmod.info`；`.disabled` 启用 / 禁用；查重复、查缺依赖；按哈希反查更新。
- 低配优化包（5.8）。

### 5.7 手机电脑同一个世界

同步分三条路走。默认那条不经过我们的任何服务器，所以主卖点对所有人免费，也不受服务器、备案和存储空间的限制。

| 传输方式 | 什么时候用 | 要不要我们的服务器 |
|---|---|---|
| **局域网直传**（默认） | 手机和电脑连着同一个 Wi-Fi | 不要 |
| **自己的网盘**（WebDAV：坚果云、群晖等 NAS，或别的支持 WebDAV 的网盘） | 不在同一个网络，又不想用 LF 云 | 不要；空间和流量是用户自己的 |
| **LF 云**（激活码） | 不在同一个网络时也能自动同步，云端另存几份历史 | 要；只给激活了的人用（D23） |

- **典型用法**：在家用电脑玩完，出门前手机连着家里的 Wi-Fi 点一下「同步」，把世界拉过去；在学校用手机玩；回家打开电脑上的 LeafStarter，手机再点一次「同步」传回来。两次交接都在家里，局域网直传就够。
- **配对**：电脑上显示一个二维码（局域网地址 + 端口 + 一次性配对密钥），手机扫一下就配好；之后同一个 Wi-Fi 下自动发现。只在局域网地址上监听，传输加密。
- **电脑端**：实例页打开「同步」→ 选传输方式（默认局域网直传）。Mod 和库文件按哈希去重；Modrinth、CurseForge、Mojang 的公共文件只记来源，另一边自己去官方源下载，不走我们的流量。
- **手机端**：列出可同步的实例 → 选目标安卓启动器 → 下载 MC 版本 + 加载器 + Mod + 存档写进它的目录（复用现在的授权目录写入）→ 一键打开那个启动器。回到 LeafStarter 时检测存档变化并传回去。
- **锁**：开始玩时登记「某设备在玩」，结束时释放；另一边看到会提示，可以强制接管（会先把对方最后一次的版本存成历史）。局域网直传时锁记在电脑上，LF 云时记在云端。
- **历史**：每个世界在电脑上保留最近几份快照，可以退回；用 LF 云的另外在云端留几份。
- **流量**：只传变化的区块文件（世界存档按 `region/*.mca` 文件粒度比较）。
- **连不上时**：学校、宿舍和公共 Wi-Fi 常常不让设备互相连（设备隔离）→ 提示改用手机热点，或者用网盘、LF 云。Windows 防火墙第一次会弹窗问要不要放行，界面上提前说明。

#### LF 云（激活码制）

- **为什么不做公开注册**：内置在启动器里的登录地址一公开，国内 MC 圈很快就能扒出背后的服务器 IP 并发起 DDoS；我们还没有备案；R2 的空间也撑不住所有人。云存档不是主卖点，跨端靠局域网直传就够了。
- **激活码就是账号**：没有用户名、密码和手机号。在启动器里输入激活码就开通；同一个人的其他设备，从已经激活的设备上扫码加入。激活码泄露了，可以在已激活的设备上换一个新码，旧码作废。
- **配额**：每个激活码有固定的空间和数量（比如 2 GB、3 个实例、每个世界云端留 5 份历史），满了就停止上传、提示清理，不扣费。码发多少由我们控制，存储总量也就可控。
- **不暴露服务器**：LF 云整个跑在 Cloudflare Workers + R2 上，没有我们自己的源站，也就没有 IP 可扒，DDoS 由 Cloudflare 挡。上传下载用 Worker 签发的短时效链接直连 R2，桶不公开；Worker 按激活码和 IP 限流，再配一条 WAF 限流规则。
- **被刷的代价**：Workers 用免费计划，被刷爆最多是当天不可用，不会产生账单；但它和官网、CurseForge 代理共用每天的免费额度，被刷时会一起受影响。R2 超出免费额度会计费 → 设预算提醒，留一个开关能一键停止上传。量大了再考虑把 LF 云拆到单独的账号。
- **备案**：Cloudflare 在境外，现在不需要备案，但国内访问速度一般。以后单独注册启动器域名、做个人备案后，国内节点只放官网和下载这类静态内容（对象存储 + CDN），不放能被打的源站。个人备案只能做非经营性网站，所以激活码要收费的话得另想办法（D23）。
- **激活码怎么发**：免费、小批量，发给内测群和朋友，不收费（D23）。

### 5.8 低配流畅、渲染器与性能调度

- 按「加载器 + MC 版本」维护一份优化 Mod 清单（以 Modrinth 上的版本兼容信息为准，不写死）。
- 新建实例时勾「流畅优先」；已有实例一键加 / 撤（撤掉时只删我们加的那几个）。
- 同时调：内存按物理内存自动分配、推荐的 GC 参数、`options.txt` 里的渲染距离等（只在首次创建时写）。

**渲染器**
- 按显卡和加载器推荐：Sodium（Fabric / NeoForge）、Embeddium（Forge）；要光影加 Iris；NVIDIA 较新的显卡可选 Nvidium；想看远景加 Distant Horizons；实验选项 VulkanMod（换成 Vulkan 渲染，和很多 Mod 不兼容，只推荐给原版或轻量实例）。
- 装之前按规则查冲突（比如 OptiFine 和 Sodium 不能一起装）。
- 手机那边：同步到 ZL2 / FCL 时，按手机的 GPU 给那边的渲染器设置一条建议（那些启动器自己有渲染器选项），只建议，不强改。

**性能调度**（实例设置里，默认「自动，不干预」；每一项都能一键撤销）
- **强制用独显**：把这个实例用的 `javaw.exe` 设成「高性能」（就是 Windows「图形设置」里那一项，用户级）。笔记本上 MC 跑在核显上，是最常见的「卡」。游戏启动后从系统的 GPU 计数器看它实际用的是哪块显卡，用错了提示。
- **只用性能核**：Intel 12 代起的大小核 CPU，把游戏进程绑到性能核上。不一定更快（MC 生成区块会用很多线程），所以默认不开，写明可能更慢。
- **切出去不降速**：Windows 11 会把后台程序降成「效率模式」，边看攻略边挂机时帧数掉得厉害；可以给游戏进程关掉这种节流。
- **进程优先级**：高于正常。
- **游戏期间用高性能电源计划**：这会改系统设置，默认关；开了的话，游戏一退就改回去。

### 5.12 联机

入口：实例页的「服务器」标签改成「联机」，服务器列表、临时联机、常驻服务器都在这里。游戏里一打开局域网，启动器角落就弹出「邀请朋友？」，端口从游戏日志里读，不用你抄。

**先分两种场景**

| | 临时联机 | 常驻服务器 |
|---|---|---|
| 什么时候用 | 你开着游戏，朋友进来一起玩；你下线就散 | 朋友随时能上，不依赖你开电脑 |
| 方式 | ① P2P 虚拟局域网（默认）② IPv6 直连 ③ 樱花穿透 ④ Radmin VPN（只识别） | ⑤ 云服务器一键开服 ⑥ 导入已有服务器 |
| 花钱 | 免费 | 云服务器按月或按年；面板服按月 |

**临时联机：自动选路**

- 朋友也用 LeafStarter（或者能互通的 HMCL / PCL）：发 P2P 邀请码。能直连就直连，打不通走中继；界面上一直显示「直连 / 中继」和延迟。
- 朋友用别的启动器或手机启动器：双方都有公网 IPv6 就给 IPv6 地址，否则给樱花地址。朋友什么都不用装。
- 走不通时说人话：「你们两边的网络都不好打洞，P2P 会走中继、延迟偏高，建议改用樱花或者开个服务器」。

① **P2P 虚拟局域网（内置，默认）**
- 用 EasyTier（开源，LGPL-3.0）。作为独立程序随启动器分发、单独进程运行，不静态链接进我们的程序，附上许可证和源码地址。
- 倾向用无网卡模式：不装虚拟网卡驱动、不要管理员权限，只转发 MC 这一个端口，朋友碰不到你电脑上的其他服务。**【待验证】**
- 中继节点先用 EasyTier 社区的公共节点和用户自己填的节点，**我们先不运营节点**（见第 8 节「联机合规」）。
- 争取和陶瓦联机的连接码互通（格式 `U/XXXX-XXXX-XXXX-XXXX`，HMCL 和 PCL2 通用），这样用 HMCL / PCL 的朋友也能直接进。**【待核实】**陶瓦的协议文档和许可证。

② **IPv6 直连**
- 国内家庭宽带很多已经有公网 IPv6。检测到双方都有，就直接给 `[IPv6 地址]:端口`，不经过任何第三方，零成本、延迟最低。
- 第一次弹出 Windows 防火墙提示时引导点「允许」；光猫或路由器拦了 IPv6 入站时，给出排查步骤。

③ **樱花穿透（SakuraFrp）**
- 好处是朋友零安装：拿到 `地址:端口` 就能进，手机启动器也行。
- 用户自己注册樱花并实名（公开资料说实名要 1 元）。启动器用用户的授权（访问密钥或樱花官方的授权方式，**【待核实】**）自动建 TCP 隧道，下载樱花官方的 frpc 来运行，然后显示地址。
- 限制直接写在界面上（以樱花官网为准）：免费隧道有数量限制；有流量时限速 10 Mbps，流量用完临时限速 4 Mbps，24 小时后恢复。几个人玩够用。
- 做成「穿透服务商」接口，以后可以接 OpenFrp 等。

④ **Radmin VPN（只识别，不打包）**
- 它是闭源软件，许可协议里看不出允许别人捆绑分发；安装还要装虚拟网卡驱动；打不通直连时走它的中转，国内常见延迟偏高。
- 做法：检测到已安装并加入了网络，就显示「你的 Radmin 地址 `26.x.x.x:端口`」并一键复制；没装就给官网链接，不替用户安装。算是给已经在用 Radmin 的人一个顺手的出口。

**⑤ 云服务器一键开服**

1. **算配置、去购买**：按实例的 Mod 数量和预计人数推荐配置（参考：阿里云的教程建议 20 人以内的中型整合包用 2 核 4G），按朋友们在哪推荐地域。打开阿里云或腾讯云轻量应用服务器的购买页，**由用户自己下单付款**。推广返佣见 D15。
2. **连上服务器**，三种方式：
   - 公网 IPv4 + root 密码：密码只用一次。登录后立刻装上启动器生成的 ed25519 公钥，以后都用密钥登录，**密码不保存**。可选「关闭密码登录」，先确认密钥能登录再关，免得把自己锁在外面。
   - 云控制台下载的密钥文件（`.pem`），或者已经配好的免密登录：直接用。
   - 密钥统一放进加密保管库（和账户令牌同一套）。
3. **开端口**：轻量服务器默认只放行 22、80、443。两种做法：按截图指引去控制台加一条 TCP 25565；或者填一个**只有防火墙权限**的子账号 AccessKey，由启动器调接口自动加（阿里云 SWAS 和腾讯云 Lighthouse 都有 `CreateFirewallRules`），用完可以删掉这个 Key。
4. **开服剧本**：固定步骤，可以重复执行（中途断了重跑不会出错），不靠 AI 临场发挥：
   - 识别系统（Ubuntu / Debian / CentOS 系），按 MC 版本装 Java（走国内镜像）
   - 装服务端：原版 / Paper / Fabric / Forge / NeoForge（复用 `loaders.rs` 的安装逻辑）
   - **把本地实例原样搬上去**：同步 Mod 和配置，按 Modrinth 的 `client_side` / `server_side` 信息剔除只在客户端用的 Mod（小地图、光影加载器之类）
   - 同意 EULA、写 `server.properties`、白名单加上朋友、开 RCON
   - systemd 服务：开机自启、崩了自动重启
   - 定时备份，保留最近若干份
   - 每一步都显示在任务面板里，展开能看到执行的命令和输出
5. **卡住了交给 AI**：某一步失败（软件源连不上、端口被占、内存不够、系统不认识）→ Agent 读输出、提方案；要在服务器上执行的命令先给你看，确认后才跑（权限分级见 5.13）。没填 AI Key 时，给出错误原因和手动处理的指引。
6. **搬世界**：可以把本地存档上传当服务器世界；服务器上的世界也能拉回电脑或手机。
7. **日常管理**：联机页显示在线人数、TPS、内存；控制台（RCON）、重启、备份、回滚。

只用 IP + 端口连游戏一般不涉及网站备案（绑域名做网站才需要）。这一点放在帮助里讲，不在流程里吓人。

**⑥ 导入已有服务器**

- **只有地址**：加进服务器列表，生成邀请码（可以附带整合包）。
- **能 SSH 登录**：登录方式同⑤第 2 步。识别已有的服务端目录，接管启停、控制台、备份、Mod 同步；已有配置不动，要改先问。
- **面板服**：MCSManager（面板地址 + API Key，默认端口 23333）、翼龙面板 Pterodactyl（客户端 API Key）。导入实例后能启停、看控制台、上传 Mod。不想碰 Linux 的人，买便宜的面板服就够了。MCSManager 管理员账号的 Key 带管理员权限，要引导用户建一个只管这台实例的子用户。

**邀请码（所有方式通用）**

- 一个短码，或者 `leafstarter://join/...` 链接。内容：连接方式（P2P 房间、IPv6、樱花地址或服务器地址）+ 实例清单（MC 版本、加载器、Mod 的来源与哈希）+ 可选的资源包。
- 只记来源、不传文件：CurseForge 的文件仍由朋友的客户端从 CurseForge 下载，符合 5.6 的条款。
- 朋友用 LeafStarter：点开 → 自动建同样的实例 → 补齐文件 → 启动后直接进服（Quick Play）。
- 朋友用手机：LeafStarter 安卓端扫码 → 把实例写进 ZL2 / FCL 的目录，把服务器加进它的服务器列表（复用现有的投递能力）。手机走 P2P 要用安卓的 VPN 接口，放到后面。
- 朋友用别的启动器：给一个 `.mrpack` 和地址。
- 邀请码可以设有效期，可以撤销。

正版验证：开服默认 `online-mode=true`；离线账户怎么处理跟着 D6 走。

### 5.13 AI 助手（Agent）与 MCP

**原则**

1. **规则先行，AI 兜底**：能写成规则或固定脚本的（常见崩溃、二分查冲突、开服剧本）都不用 AI，因为快、免费、离线、结果稳定。AI 只接规则认不出的情况。
2. **一套工具，三个入口**：修复按钮、内置 Agent、对外 MCP 共用同一份工具注册表（`agent/tools.rs`）和同一套权限规则。M3 做修复按钮时就按这个结构写，后面接 AI 不用返工。
3. **不绑模型、不强制付费**：不填 Key，除 AI 以外的功能全部可用。
4. **动手前说清楚**：Agent 每一步在做什么都显示在面板上；会改东西的操作先建快照，可以一键撤回。

**能做的事**

| 场景 | 怎么做 |
|---|---|
| 崩溃排查 | 规则没认出时启用：读本次日志、崩溃报告、Mod 列表和元数据，必要时查 Modrinth / CurseForge 上的版本信息 → 说清原因、给修复方案 → 你确认后执行 → 自动重启验证，最多 3 轮。修不好就整理一份能直接发给 Mod 作者的报告 |
| 二分查冲突 Mod（不需要 AI） | 建快照 → 每轮禁用一半 Mod（有依赖关系的一起进退）→ 启动到主菜单判断好坏 → 约 log₂N 轮定位（200 个 Mod 约 8 轮）→ 恢复快照，只禁用找出来的那个 |
| 开服兜底 | 见 5.12 ⑤ 第 5 步 |
| 配整合包 | 「1.20.1 Fabric，科技向，轻薄本能跑」→ 搜 Mod、查兼容和依赖、列清单 → 确认后建实例 |
| 启动器自己出错 | 打包诊断信息（打过码的）、写好问题描述，确认后打开 GitHub 的新建 Issue 页面 |

**模型接入**

- 可以配多个「AI 源」，每个源：名字、接口类型、地址、Key（进保管库）、模型。接口类型四种：
  - **Anthropic**：Claude，走原生的 Messages 接口，默认 `claude-opus-5-5`；
  - **OpenAI 兼容**：DeepSeek、通义千问、Kimi、智谱等云端服务，以及本机的 llama.cpp server、LM Studio、vLLM，都是这种；
  - **Ollama**；
  - **生图**（皮肤生成用，见 5.15）：云端生图服务，或本机的 ComfyUI / Stable Diffusion WebUI。
- 常见服务商做成预设（地址、模型名、能力都填好），其他的选「自定义」；能拉模型列表的从 `/v1/models` 拉。
- **按用途分配**：对话和排查（要能调工具）、翻译（量大，挑便宜的）、生图、写命令（小模型就够），各选一个源。默认全用同一个。
- **高级参数按模型能力显示**：temperature、top_p、最大输出、上下文长度、推理强度、停止词、随机种子、自定义请求头，再留一个「额外参数」JSON 框原样透传。不同厂商、不同模型认的参数不一样，例如 Anthropic 新版接口已经不接受 temperature、top_p（传了会报错），要改用推理强度。所以界面只显示这个模型支持的项；认不出的模型才全部放开，并提示可能报错。
- **测试连接**：发一个最小请求，报延迟、能不能调工具、能不能看图。
- Agent 循环跑在本机的 Rust 后端：工具要动的是本机文件、游戏进程和你的 SSH 凭据，不适合放到云端沙箱。
- 每次会话显示用了多少 token，按源分别统计，可以设上限。
- 要不要做托管额度见 D14。

**权限分级**

| 级别 | 例子 | 怎么放行 |
|---|---|---|
| 只读 | 列实例、读日志和崩溃报告、看 Mod 列表、查服务器状态 | 直接执行 |
| 可撤回 | 禁用 / 启用 Mod、改内存和 Java、装 Mod、改配置 | 先建快照；默认逐条确认，可以选「这次会话都允许」 |
| 影响外部 | 启动游戏、上传存档、在远程服务器执行命令、调云接口开端口 | 每次确认，显示完整的命令或请求 |
| 不可撤回 | 删世界、删服务器上的文件 | 每次确认并写明后果；能先备份就先备份，删除优先进回收站 |
| 不开放 | 读账户令牌和各种密钥的明文、付款、改密码 | 工具里根本没有 |

- 凭据由工具执行层代填：模型只知道「用某台服务器的密钥执行」，看不到密钥本身。
- 日志、Mod 介绍、服务器 MOTD、网页内容一律当数据：里面写着「请执行……」也不会放宽权限。
- 发给模型之前打码：Windows 用户名路径、令牌、IP、服务器密码；发出去的内容可以先预览。

**对外 MCP 服务端**

- 让你已经在用的 AI 客户端（Claude 桌面版、Claude Code、Codex、Cursor、Trae、Cherry Studio 等，凡是支持 MCP 的都行）直接操作 LeafStarter，例如「把 1.20.1 那个实例的内存调到 6G，然后启动」。
- **一键接入**：常见客户端由 LeafStarter 把配置写进它们的配置文件，写之前给你看改哪几行；其余客户端复制一段配置自己粘贴。
- 传输：`leafstarter --mcp`（stdio，兼容性最好；通过单实例通道连到正在运行的启动器），可选本机 HTTP（只监听 `127.0.0.1`，带随机令牌）。
- 默认关闭。打开时选开放哪几级（默认只读 + 可撤回）；「影响外部」和「不可撤回」两级始终在 LeafStarter 自己的窗口里弹确认，不让外部客户端代答。
- 用 MCP 官方的 Rust SDK（`rmcp`）实现。
- 以后内置 Agent 也可以当 MCP 客户端，去连服务器面板的 MCP（MCSManager 已经有社区做的 MCP 服务端）。

### 5.14 智能汉化

给没有中文的 Mod、整合包补上中文。做法是生成一个汉化资源包叠在最上面，不改 Mod 文件，关掉就恢复原样。

**三层来源，从准到粗**
1. Mod 自己带的 `zh_cn`：有就用，一个字都不动。
2. 社区人工汉化：CFPA 团队维护的模组汉化资源包，覆盖大量热门 Mod，质量最好（许可见 D19）。
3. 机器 / AI 补齐：前两层都没有的条目才翻。
   - 机器翻译：接各家翻译接口（多数有每月免费额度），或下载「离线翻译」（开源模型，质量一般，但不联网、不花钱）。离线翻译不随任何安装包带，见 5.17。
   - AI 翻译：用 5.13 里分给「翻译」的 AI 源，带上下文（这个 Mod 是干什么的、同一物品的其他条目）和术语表，质量明显好于机器翻译。

**术语表**：从游戏自带的英文、中文语言文件自动对出原版术语（Iron Ingot → 铁锭、Redstone → 红石），再叠上社区汉化里的 Mod 术语。这样「铁锭」不会被翻成「铁块」「铁条」。

**翻什么**
- 物品、方块、界面、提示：`assets/<modid>/lang/en_us.json`（1.12 及以前是 `en_US.lang`）。
- 指南书：Patchouli 等手册的 JSON。
- 任务：FTB Quests 新版本走语言文件，能直接翻；老版本把文字写在任务配置里，要改整合包的配置文件（先备份，可以撤回）。

**要防的坑**
- 格式符原样保留：`%s`、`%1$s`、`§a`、`{0}`、`\n`。翻完逐条校验，对不上的退回英文。
- 只补缺的，不覆盖已有的中文。
- 动手前先估算：多少条、大概多少字或 token、预计花多少钱；可以只翻其中几个 Mod。
- 按「原文哈希」缓存译文，Mod 更新后只翻新增和改过的条目。
- 机器 / AI 的译文只在本机生成、只给自己用，不公开分发。

**界面**：实例页「Mod」里每个 Mod 标出「自带中文 / 社区汉化 / AI 补的 / 没中文」，再给一个「补全中文」按钮。

### 5.15 皮肤工作台

**编辑器**
- 64×64 皮肤，两层（身体层和外套层），Steve（4 像素手臂）和 Alex（3 像素手臂）两种体型。
- 画笔、填充、取色、橡皮、左右镜像、只画某个部位；3D 预览（skinview3d，MIT 许可）实时跟着变，可以拖着转、摆姿势。
- 从 PNG 导入、从正版档案导入当前皮肤；每次保存都留历史版本。

**AI 生成**（结果都落进编辑器，可以接着改）
1. **描述 → 程序画**（默认，最稳）：文字模型把「穿蓝色卫衣、戴黑框眼镜的程序员」拆成每个部位的颜色、图案、配饰，再由我们的绘制器按皮肤的 UV 布局画出来。任何文字模型都能用，便宜。
2. **生图模型画立绘 → 转成皮肤**：用生图接口画角色的正面和背面，再像素化、压缩调色板、贴到对应部位。效果看运气，适合当草稿。
3. **专门的皮肤生成模型**：接本机的 ComfyUI / SD WebUI（社区有专门训练过的皮肤模型），作为高级选项。

**换上**
- 正版账户：调 Minecraft 官方接口上传皮肤、切换披风（只能选自己拥有的），一键换上。
- 离线账户：只有自己看得到，要靠 CustomSkinLoader 一类的 Mod；想让别人也看到，就用外置登录（比如 LittleSkin 这类皮肤站）。
- 你的皮肤会站在每个实例的风景头图里（原型里那个小人）。

### 5.16 不进游戏也能管世界

都在实例页的「存档」里：每个世界点开有「信息 / 地图 / 查找 / 设置」。

**设置模板（键位、FOV 等）**
- 从任意实例导入 `options.txt` 里的键位、FOV、鼠标灵敏度、音量、视距等，勾选要哪些项，套用到别的实例；新建实例自动套用默认模板。
- 跨版本换算：1.12 及以前的键位用数字键码，1.13 起用 `key.keyboard.*`，自动转换。Mod 的键位多数也写在 `options.txt` 里，一起带上。
- 同步到手机时不带键位（触屏操作不一样）。

**世界信息**：读 `level.dat`：种子（一键复制）、游戏模式、难度、版本、游戏时长、出生点、作弊开关、游戏规则；玩家的位置、生命、背包。

**新建和修改世界**
- 局外新建：写好 `level.dat`（种子、模式、难度、世界类型、游戏规则、数据包），地形等进游戏时再生成。不同版本的 `level.dat` 结构不一样，按版本段做模板；不支持的版本就提示「进游戏里建」。
- 局外修改：游戏模式、难度、作弊、游戏规则、时间天气、出生点。改之前自动备份；游戏正开着这个世界时不让改（检查 `session.lock`）。

**世界地图**：读 `region/*.mca` 画俯视图（Rust 的 fastanvil 能直接渲染），能缩放拖动，标出出生点、玩家位置、死亡点；地表、地下、下界分层看；Mod 方块用它材质的平均色。

**查找区域、区块、建筑**
- 已经生成过的区域：读区块里记录的结构（村庄、要塞、神殿……），列出坐标、离出生点多远。
- 还没生成的区域：按种子推算原版的结构和群系（cubiomes，MIT 许可的 C 库），类似 Chunkbase。Mod 改了地形生成就不准，界面上写明。

**局外指令台（默认关闭）**
- 在后台用同版本、同服务端 Mod 起一个无界面的本地服务器加载这个世界，通过 RCON 执行命令，执行完存档、关掉。
- 每次执行前先给世界建快照，所以算「可撤回」：不满意一键回滚。
- AI 辅助：说「在出生点造一个 9×9 的玻璃平台」，AI 写成 `/fill` 命令，执行前给你看。
- 局限：只装在客户端的 Mod 不生效；第一次要下载服务端（复用 5.12 的开服剧本）。

### 5.17 功能包与发行形态

**哪些做成功能包**：只有三类，其余都缝进主程序。
1. 带独立程序的：P2P 联机（EasyTier）、局外指令台的本地服务端；
2. 数据大的：离线翻译模型、方块颜色表、汉化词库；
3. 会在后台跑、会开端口的：联机、指令台。

| 功能包 | 里面有什么 | 估计大小 |
|---|---|---|
| 联机 | EasyTier 程序 | 十几 MB |
| 世界工具 | 地图渲染、cubiomes、方块颜色表 | 几 MB |
| 离线翻译 | 开源翻译模型 | 上百 MB，**只按需下载**，见下 |

（大小是估计，做出来再量。）

**离线翻译单独对待**（e 总 11-22 定）：
- 不随任何安装包带，便携全功能版里也没有。只有用到汉化、又不想用 AI 和翻译接口时，才提示下载。
- 下载源：我们自己的分发是 R2 + 蓝奏云双源，扛不住几百 MB 的量。所以模型文件直接从模型的发布地址下（国内走魔搭社区 ModelScope，海外走 Hugging Face）；我们的服务器只发一个几 KB 的签名清单（文件名、大小、SHA-256），下载完逐个校验，对不上就删掉重下。
- 先确认选用的模型许可允许这样分发和使用（多数开源翻译模型是 Apache-2.0 或 MIT，选型时核实）。

说实话，除了离线翻译，全部装上也不算大。分包真正的好处是：不用的功能不跑、不开端口、不占后台；P2P 组网这类程序容易被杀毒软件误报，单独成包不会连累主程序；界面上也能少一些入口。

**怎么实现**
- 功能包 = 签名的独立程序 + 数据 + 清单（版本、需要的主程序版本、要哪些权限：联网、开端口、读写哪些目录）。
- 从我们自己的服务器下载，校验 ed25519 签名和哈希，装进应用数据目录的 `ext/`；装完立即可用，不用重启。
- 主程序和功能包通过标准输入输出说 JSON-RPC。功能包崩了不影响主程序。
- 功能包对应的界面随主程序带着（几十 KB）；没装时，入口写着「装上这个功能包（约 12 MB）」。
- 功能包就是官方插件，和第三方插件走同一套接口和权限；第三方插件按 5.18 分步开放。
- 另有「简洁界面」开关：把不用的入口藏起来，和装没装功能包无关。

**发行形态**

| | 适合谁 | 说明 |
|---|---|---|
| **安装版**（默认推荐） | 大多数人 | 开始菜单、自动更新、注册 `leafstarter://`（点邀请链接直接打开）；起步是精简的，功能包按需装 |
| **便携版 · 精简** | 想要一个文件的人 | 一个 exe，数据放在旁边的 `data/`；功能包也能装，装在旁边的 `ext/` |
| **便携版 · 全功能** | U 盘带着走、机房、网吧 | 一个 zip，解开就是主程序加联机、世界工具两个功能包（不含离线翻译模型） |

- 不做「单个 exe 自解压出全部功能」：自解压程序最容易被杀毒软件误报，误报对新启动器是致命的。
- 便携版需要系统里有 WebView2（Windows 11 自带，Windows 10 绝大多数也有），没有就提示安装。
- 安卓端不做功能包，安卓只管同步和投递。

### 5.18 插件与定制版（Everything is Plugins）

e 总 11-23 提出：把几乎所有架构端口开放给开发者，像 MC 和 Mod 一样。开发者能做插件加功能、改界面、换字体，甚至裁剪功能，做极简版，或者做专门启动自家整合包的启动器；我们只要求署名。下面是探究的结果。

**先说结论**
1. **方向对，但「开放」和「完全信任」要分开。** 能扩展的地方尽量多，能碰到的东西按权限给。启动器手里有微软账户令牌、SSH 私钥、云 AccessKey、模型 Key。如果插件代码能直接拿到这些，第一个恶意插件就可能连累所有用户：微软客户端 ID 是大家共用的，出了盗号事件，整个应用都可能被停。先例是 2023 年的 fractureiser：攻击者在 CurseForge 和 Bukkit 上发布被篡改的 Mod 和插件，偷 Minecraft、Discord 令牌和浏览器里的登录信息。
2. **拉新最快的不是插件市场，而是「定制版」。** 服主和整合包作者给自己的玩家发「XX 服专用启动器」，每个定制版都带着「基于 LeafStarter」进到几百个玩家手里。插件生态要等用户多了才长得起来，定制版从第一天就能带来用户。
3. **许可证。** 原来仓库没有许可证文件，公开仓库没写许可，默认是保留所有权利，别人在法律上不能改了再发。11-23 已定 Apache-2.0（D20）。
4. **「一切皆插件」先用在自己身上。** 联机、汉化、皮肤、世界工具、AI、MCP 这些官方功能，都用和第三方一样的插件接口来写。接口够不够用、好不好用，我们自己最先知道。5.17 的功能包就是官方插件。

**分四层开放**（越往下能力越大、门槛越高）

| 层 | 能做什么 | 怎么运行 | 谁能发 |
|---|---|---|---|
| ① 外观 | 主题颜色、字体、圆角、背景、图标包、音效、头图画风、语言包 | 纯数据，不跑代码。样式只能引用包里自带的图片和字体，不能连外网 | 任何人 |
| ② 声明式扩展 | 崩溃规则、下载镜像、实例模板、主页卡片（服务器公告、活动）、外置登录预设、推荐 Mod 清单、命令面板条目、汉化术语表 | 纯数据（JSON），由启动器解释执行 | 任何人 |
| ③ 脚本插件 | 自己的页面、卡片、标签页、设置；监听启动 / 退出 / 崩溃；调用启动器的能力（装 Mod、改设置、开房间……）；给 AI 助手和 MCP 加工具 | HTML / JS / TS，跑在没有任何系统权限的隔离环境里，只能通过插件接口办事；每个接口按清单里声明的权限放行 | 任何人；上官方市场要求源码公开 |
| ④ 原生插件 | 带独立程序的（类似 EasyTier）、需要本机原生能力的 | 独立进程，JSON-RPC 通信 | 实名认证的开发者，人工审核 |

参照：PCL2 的「自定义主页」（服主写一份 XAML，启动器远程加载）就是第 ② 层的先例，服主用得很多。Zed 编辑器的扩展编译成 WebAssembly、跑在沙箱里、按能力授权，是第 ③④ 层的参照。

隔离怎么做还要实测（**【待验证】**）：有资料说 Tauri 在 Linux 和安卓上分不清请求是 iframe 发的还是主窗口发的。所以插件界面要么放进单独的 webview、一点 IPC 权限都不给，要么实测确认 iframe 拿不到 IPC 再用 iframe。插件逻辑需要高性能或原生能力时，以后可以加 WebAssembly 运行时（`wasmtime`，参照 Zed）。

**能扩展的地方（贡献点）**
- **外观**：主题变量、字体、背景、头图生成器、启动动画、音效、图标、语言。
- **布局插槽**：顶栏、左栏底部、实例页的标签和概览卡片、启动按钮旁、设置页分组、命令面板、右键菜单、新页面。插件往插槽里放东西，不直接改别人的页面结构；这样官方界面改版时，插件不会一起坏掉。官方自己的卡片和标签页也是这样放进去的。
- **实例与资源**：导入导出格式、实例模板、下载源和镜像、资源平台、推荐清单。CurseForge 只开放「搜索、安装」这类固定能力，不开放原始请求（Key 不能给第三方，见 D7）。
- **启动**：启动前 / 后的钩子、日志解析、崩溃规则和修复动作、性能预设。
- **账户**：外置登录服务器（authlib-injector）预设、皮肤站。
- **联机**：中继节点、服务器列表、开服模板和面板。
- **AI**：插件写的工具自动出现在 AI 助手和 MCP 里，跟官方工具走同一套权限分级（5.13）。AI 源预设、提示词模板也能扩展。
- **世界工具**：地图图层、Mod 加的建筑的查找。
- **汉化**：翻译引擎、术语表。
- **整套换界面**（「换壳」）：只给第 ④ 层和定制版作者，用来做风格完全不同的启动器。换了壳也拿不到令牌和密钥，原因见下。

**永远不开放**
- **账户令牌、保管库里的密钥明文、我们的 CurseForge Key、签名私钥。** 这些只在 Rust 后端里，连官方界面都拿不到，插件更拿不到。插件要「用正版账户启动游戏」，只能调「启动」这个接口。
- **悄悄加 `-javaagent` 或改 JVM 参数。** 这等于在游戏进程里跑任意代码，而游戏进程本来就拿着访问令牌。外置登录要用的 authlib-injector 由启动器内置（固定哈希）。插件想加别的 agent，必须单独申请高危权限，安装时明说。
- **悄悄装别的插件、改别的插件、关掉安全提示。**

**权限**
- 插件清单里列出要的权限，安装时用大白话给用户看，比如「读你的实例列表」「访问 api.example.com」「改启动参数（高危）」。
- 更新后权限变多，要重新同意。
- 账户信息只给用户名和 UUID。

**防坏插件**（吸取 fractureiser 的教训：作者账号被盗后，攻击者推送恶意更新）
- 作者用自己的密钥签名，插件市场再签一次；新版本先过自动扫描再上架。
- 吊销名单：发现恶意插件，启动器联网时自动停用并提示。
- 每个插件单独隔离：一个崩了不影响主程序和别的插件；出错时告诉你是哪个插件。
- 安全模式：按住 Ctrl 打开 LeafStarter，所有插件都不加载。
- 分级标记：官方 / 已审核 / 社区 / 本地开发。社区和本地开发的插件，安装时有明显提示。

**定制版**（给服主和整合包作者）
- 内容：一个签名的「定制包」文件，写着名字、图标、主题、字体、开哪些官方插件、装哪些第三方插件（锁定版本和哈希）、预装的整合包、服务器列表、主页内容、更新地址、锁定的设置。
- 用法：放在 LeafStarter.exe 旁边（便携版），或者导入安装版，打开就是定制版的样子。exe 还是我们签名的那一个：
  - 不用重新编译，杀毒软件不误报；
  - 主程序跟着官方自动更新，定制包跟着作者的地址更新。
- 能做到多精简：不需要的全部关掉，可以做成「打开就一个启动按钮」的极简启动器。
- 署名是天然存在的：定制模式的「关于」和启动画面固定写「基于 LeafStarter」；微软登录页上显示的也是 LeafStarter，因为用的是我们的客户端 ID。
- 为什么不让大家直接改源码另发：Mojang 现在要求新建的 Azure 应用先申请、批准后才能调 Minecraft 的接口；改源码另发的启动器要用自己的客户端 ID 单独申请，CurseForge 的 Key 也要自己申请。定制版跑的就是我们的程序，这些都省了。对服主来说，定制版比改源码省事得多，我们也更容易保证安全。
- 定制版制作器：网页或启动器里的一个向导。填表、拖图标、选整合包，导出定制包，不用写代码。
- 局限：exe 文件本身的图标是编译进去的，定制版换不了；快捷方式和窗口里的图标可以换。

**许可和署名**（D20、D22）
- 主程序：**已定 Apache-2.0**（D20）。允许任何人用、改、发（包括商用），要求保留版权声明和 `NOTICE` 文件，并且附专利授权。`NOTICE` 里写着「本产品包含 LeafStarter 的代码」，衍生版本必须把它带上（放在 NOTICE 文件、文档或界面里，三选一）。
- 另附一份「名称、图标与署名政策」（`TRADEMARKS.md`）：LeafStarter 的名字和图标不随代码授权；改源码另发的版本不能叫 LeafStarter，要写「基于 LeafStarter」，还要换成自己的微软客户端 ID、CurseForge Key 和更新服务器。
- 要说清楚的一点：Apache-2.0 和 MIT 都只要求在许可文件里保留署名，没法强制别人在界面上显示「基于 LeafStarter」。如果非要在许可证里强制界面署名，就不算标准开源许可证了，很多开发者会因此不碰。所以建议许可证用标准的，界面署名靠两样：定制版自带，商标政策要求。
- 插件 SDK 和类型定义：用 MIT。插件是作者自己的作品，用什么许可随他们。
- 第三方许可清单已经补上（`THIRD-PARTY-NOTICES.md`）：界面图标来自 lucide（ISC，从 Feather 继承的图标另按 MIT）。编译后的程序还带着 Rust 依赖，发布时用 `cargo-about` 自动生成完整清单（M6）。

**分发和带宽**
- 插件市场的索引放在 GitHub 上一个公开仓库里，提 PR 上架（Obsidian 也是这么做的）。索引只存插件信息、版本、签名和 SHA-256。
- 插件文件由作者自己托管：GitHub Releases、Gitee、蓝奏云、自己的服务器都行。启动器下完对哈希，对得上才装。
- 我们自己的服务器只发几 KB 的索引，不占 R2 和蓝奏云。定制包同理。

**开发者体验**
- `npm create leafstarter-plugin` 生成模板；有 TypeScript 类型定义。
- 开发者模式：本地插件改了就热重载，出错有调试面板。
- 文档站：每个贡献点配一个例子，示例插件全部开源。
- 顺带的好处：开发者用 Claude Code 这类工具写插件时，可以通过我们的 MCP 服务端直接在 LeafStarter 里装上测试。

**代价**
- 接口一旦公开就要长期兼容。1.0 之前标「实验」；1.0 以后按语义化版本，废弃的接口至少保留两个大版本。
- 文档、审核、答疑都要人手：插件市场开张前，先想好审核量怎么扛。
- 用户装了插件出问题会来找我们，所以错误提示要能指出是哪个插件。
- 插件宿主加接口是 L 到 XL 的工作量。所以**分步开**（D21）：
  1. 先在内部把官方功能按插件来写，不对外；
  2. 开放定制版；
  3. 开放外观和声明式扩展，上线插件市场索引；
  4. 开放脚本插件和 SDK；
  5. 最后开放原生插件。

## 8. 风险

- **CurseForge 审核和条款**：条款要求申请人年满 18 岁（或有完全民事行为能力）、所填信息真实；Key 不能给第三方；API 数据不能缓存。没批下来之前，资源中心先只接 Modrinth。
- **CurseForge 分发限制**：部分文件不允许第三方下载 → 引导手动下载。
- **跨端同步的边界**：手机端只能在打开 LeafStarter 时同步；部分 Mod 在安卓启动器上跑不了 → 同步前提示「这个实例里有 N 个 Mod 在手机上可能不兼容」（按已知列表）。
- **存储成本**：LF 云只给激活码用户，每个码配额固定，码发多少由我们定；公共文件只记来源不上传；历史快照有数量上限。默认的局域网直传和网盘不占我们的存储。
- **服务器被扒 IP、被 DDoS**：国内 MC 圈常见。应对：不做公开注册的账号系统；LF 云、自动更新、CurseForge 代理都放在 Cloudflare Workers + R2 上，没有自己的源站 IP；启动器不直连任何自己服务器的 IP；按激活码和 IP 限流。代价：这些服务共用 Workers 每天的免费额度，被刷时会一起不可用（不会多花钱），量大了再拆分。
- **备案**：现在的服务都在境外的 Cloudflare 上，不需要备案，但国内访问慢。以后单独注册域名、做个人备案后，国内只放静态内容；个人备案不能做经营性服务（D23）。
- **按 IP 放开离线账户（D6）判错**：开着全局代理或 VPN 的大陆玩家会被当成海外 → 判断时先绕过系统代理直连，联网失败看系统地区；真判错了，登录一次正版就行。
- **Java 建不了本机管道**：有的电脑上（装了某些加速器、安全软件）用户目录里建不了 AF_UNIX 套接字文件，Java 17+ 报「Unable to establish loopback connection」，联机和进服务器都会坏。应对：启动前用 Windows 接口试一下默认临时目录，不行就换到 `C:\Users\Public\LeafStarter\sock` 这类能用的目录，用 `-Djdk.net.unixdomain.tmpdir` 告诉 Java（11-24 在 e 总电脑上遇到并验证）。
- **局域网直传连不上**：设备隔离、防火墙拦截 → 提示改用手机热点或网盘；防火墙弹窗提前说明。
- **Forge 各代差异**：靠 M2 的验收矩阵回归。
- **杀毒软件误报**：没签名的程序又会起 Java 进程 → 尽早做代码签名。
- **商标**：不用 Mojang / Minecraft 的标志，注明「非 Minecraft 官方产品，与 Mojang 和 Microsoft 无关」。
- **新版本号格式（26.x）**：版本排序、Java 需求一律以版本 JSON 为准。
- **联机合规**：2025 年 10 月以来，第三方启动器联机在志愿节点、云服务器合规、法律风险上一直有争论。我们先不运营中继节点、不收联机费用；要自建节点之前先做法律评估。
- **第三方条款**：樱花允不允许第三方程序代建隧道、Radmin 的分发许可、EasyTier 的 LGPL（独立进程分发并附源码地址）、陶瓦协议的许可，动手前逐个核实。
- **远程服务器误操作**：开服剧本只做固定、可重复执行的步骤；Agent 在服务器上执行的每条命令都要确认；改配置前先备份。
- **AI 的费用和合规**：自带 Key 的费用由用户自己承担，界面上显示用量；托管额度另有服务地区和备案问题，见 D14。
- **凭据泄露**：SSH 私钥、云 AccessKey、樱花密钥、模型 Key 都加密保存；引导用户用最小权限的子账号。
- **功能越堆越多**：同学们的点子都不错，但一个人加 AI 做不完。按里程碑的顺序来：公测前只做核心；工具箱类功能（汉化、皮肤、世界工具）都排在公测后，能做成功能包的就做成功能包，不拖慢主程序。
- **汉化的许可和质量**：社区汉化包按许可署名、不商用；机器 / AI 译文只在本机用、不分发；给「这条翻得不对」的入口，先记在本地。
- **改世界把存档弄坏**：局外修改、指令台一律先快照；游戏开着时不让动；不同版本的 NBT 结构差别大，只支持测过的版本段。
- **性能调度反而更慢**：默认不干预；每一项都能一键撤销；「只用性能核」写明可能更慢。
- **恶意插件**：MC 社区有先例（2023 年的 fractureiser 通过被篡改的 Mod 偷令牌）。应对：令牌和密钥不进任何插件接口、权限清单、双重签名、自动扫描、吊销名单、安全模式。
- **连累微软应用**：所有用户共用一个客户端 ID，一旦出现借我们的程序盗号的事件，应用可能被停。所以「加 javaagent / 改 JVM 参数」是高危权限，外置登录的 authlib-injector 由我们内置。
- **仿冒定制版**：有人拿定制版的样子冒充官方、夹带恶意插件。应对：定制包必须签名，第三方插件锁哈希；「关于」页显示定制包作者和签名信息。
- **接口维护成本**：公开的接口要长期兼容；1.0 前标实验，之后按语义化版本走。
- **许可证生效前就宣传开放**：许可证和政策 11-23 已经写进仓库（D20），推送到 GitHub 之后才算公开生效；在那之前别对外说「开放」。
- **许可证发出去就收不回**：已经按 Apache-2.0 发布的版本，别人永远可以按 Apache-2.0 用。以后如果想给新版本换许可，别人贡献进来的代码要征得他们同意；所以开始收外部贡献之前，先想好要不要签贡献者协议。
